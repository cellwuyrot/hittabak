# Стики — интернет-магазин табачных стиков

Лендинг + интернет-магазин табачных стиков. Построен на базе шаблона [shablon-at-all](https://github.com/acoulbot/shablon-at-all).

## Стек технологий

- **Next.js 16** (App Router, Turbopack)
- **TypeScript**
- **Tailwind CSS 4**
- **Prisma 7** + SQLite (адаптер better-sqlite3)
- **JWT** аутентификация
- **Resend** для отправки email

## Возможности

### Для покупателей
- Главная страница со слайдером рекламных баннеров
- Каталог товаров с фильтрами (цена, тип, бренд, цвет)
- Вложенные категории с SEO-оптимизированными URL
- Карточки товаров с галереей, отзывами, рекомендациями
- Корзина, избранное, сравнение товаров
- Покупка упаковкой со скидкой 10%
- Быстрый заказ в 1 клик
- Регистрация/вход по email с верификацией
- Личный кабинет (профиль, заказы, адреса)
- Новости и акции
- Форма обратного звонка
- Адаптивная вёрстка для всех устройств
- PWA (Progressive Web App)

### Админ-панель (`/admin`)
- Управление товарами (CRUD, поиск, пагинация, превью)
- Приватные заметки администратора к заказам и заявкам (покупателю не отображаются)
- Импорт/экспорт товаров через Excel (XLSX)
- Управление категориями с изображениями
- Управление слайдером (загрузка файлов, сортировка)
- Управление новостями
- Управление заказами
- Раздел «Клиенты» с данными покупателей
- Редактирование страниц сайта (О компании, Доставка и т.д.)
- Статистика посещений (графики, уникальные/просмотры, топ страниц)
- Массовое удаление товаров
- Массовое обновление остатков
- ИИ-генерация описаний товаров (OpenAI)
- Мета-теги товаров (keywords) с индикатором заполненности
- Раздел «Отзывы»:
  - ИИ-генерация отзывов от вымышленных покупателей (напр. «Василий А.») — через нейросеть Google Gemini при наличии ключа, иначе встроенный локальный генератор
  - Генерация одним кликом для конкретного товара или массово для всех товаров без отзывов
  - Ручное добавление/редактирование, публикация/скрытие, удаление отзывов
  - Загрузка отзывов через таблицу (XLSX/CSV) с автоматической привязкой к существующим товарам по названию, артикулу или штрихкоду + шаблон для скачивания

### SEO
- Schema.org разметка (Product, Organization, WebSite, BreadcrumbList, LocalBusiness, FAQ)
- Rich Snippets (рейтинг, цена, наличие в поиске)
- Open Graph и мета-теги для всех страниц
- Динамический OG Image
- XML Sitemap
- robots.txt
- Canonical URL для всех страниц
- Хлебные крошки

### Аналитика
- Встроенная статистика посещений (с фильтрацией ботов)
- Поддержка Яндекс.Метрики
- Поддержка Google Analytics
- Cookie-based уникальные посетители
- Отслеживание SPA-навигации

### UI/UX
- Skeleton loading при загрузке
- Ripple-эффект на кнопках
- Анимация добавления в корзину (fly-to-cart)
- Анимированные фильтры каталога
- Scroll Reveal анимации
- Glassmorphism на странице входа
- Toast-уведомления

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/acoulbot/stiki.git
cd stiki

# 2. Установить зависимости
npm install

# 3. Скопировать .env файл
cp .env.example .env

# 4. Создать БД и применить миграции
npx prisma migrate dev

# 5. Заполнить БД тестовыми данными
npm run seed

# 6. Запустить dev-сервер
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Вход в админ-панель

- **URL:** [http://localhost:3000/admin](http://localhost:3000/admin)
- **Логин:** `admin`
- **Пароль:** `admin123`

## Переменные окружения

| Переменная | Описание | Обязательна |
|---|---|---|
| `DATABASE_URL` | Путь к SQLite файлу | Да |
| `JWT_SECRET` | Секрет для JWT токенов | Да (в production) |
| `RESEND_API_KEY` | API ключ Resend для email | Нет |
| `RESEND_FROM_EMAIL` | Email отправителя | Нет |
| `NEXT_PUBLIC_BASE_URL` | Домен сайта | Да (в production) |
| `NEXT_PUBLIC_YANDEX_METRIKA_ID` | ID Яндекс.Метрики | Нет |
| `NEXT_PUBLIC_GA_ID` | ID Google Analytics | Нет |
| `OPENAI_API_KEY` | Ключ OpenAI для ИИ-описаний | Нет |
| `GEMINI_API_KEY` | Ключ Google Gemini (AI Studio) для ИИ-генерации отзывов. Если не задан — используется встроенный локальный генератор | Нет |
| `GEMINI_MODEL` | Модель Gemini (по умолчанию `gemini-2.5-flash`) | Нет |

## Безопасное обновление каталога на production

Новая структура категорий: **Устройства/Стики → Бренд → Модель → Цвет**. Схема БД не меняется: используется существующая самоссылка `Category.parentId`, поэтому миграция Prisma для этой доработки не нужна, а старые данные остаются совместимыми.

1. Сначала сделайте штатную резервную копию каталога и файла SQLite.
2. Установите код и зависимости, но не запускайте `seed` на production.
3. Проверьте план преобразования (БД не изменяется):
   ```bash
   npm run catalog:migrate
   ```
4. Примените преобразование:
   ```bash
   npm run catalog:migrate -- --apply
   ```
   Перед изменением скрипт автоматически создаст рядом с БД файл `*.backup-before-catalog-*`. Скрипт не удаляет товары, заказы, категории или иные записи; он создаёт недостающие уровни и меняет привязки товаров.
5. Выполните `npm run build`, перезапустите приложение и проверьте `/catalog`, `/catalog/devices`, `/catalog/sticks` и создание товара в `/mainenter`.

Повторный запуск безопасен: уже созданные категории используются повторно. В админке удаление категории с товарами или дочерними категориями теперь блокируется.

### Обновление с заметками к заказам и заявкам

Перед сборкой примените добавочную миграцию. Она не пересоздаёт таблицу и не изменяет существующие заказы:

```bash
npx prisma migrate deploy
npm run build
```
